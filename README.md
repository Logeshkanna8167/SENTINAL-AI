Sentinel AI Infrastructure Monitoring System

Overview

Sentinel AI is an AI-powered Infrastructure Monitoring System designed to monitor the health of critical infrastructure such as bridges, buildings, towers, and industrial structures. The system collects sensor data, analyzes structural conditions in real time, predicts potential failures using machine learning, and generates alerts for proactive maintenance.

Features

Real-Time Sensor Monitoring

* Simulates vibration, acoustic, temperature, and tilt sensor data.
* Continuously tracks infrastructure health parameters.
* Displays live monitoring information through an interactive dashboard.

AI-Based Failure Prediction

* Uses machine learning models to analyze sensor patterns.
* Predicts structural degradation and potential failures.
* Provides risk scores based on current conditions.

Risk Assessment Engine

* Calculates infrastructure health status.
* Categorizes risk levels as:
    * Low Risk
    * Moderate Risk
    * High Risk
    * Critical Risk

Alert System

* Sends instant Telegram notifications when abnormal conditions are detected.
* Provides early warning for preventive maintenance.

Interactive Dashboard

* Live sensor visualizations.
* Infrastructure health analytics.
* Risk trend monitoring.
* Performance insights and statistics.

Risk Heat Map

* Visual representation of structural risk levels.
* Highlights critical zones requiring attention.
